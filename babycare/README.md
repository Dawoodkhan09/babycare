# 🍼 BabyCare — Pakistani Baby Healthcare Platform

A full-stack healthcare web application for parents and homeopathic doctors in Pakistan.

## 🌟 Features

### 👨‍👩‍👧 For Parents
- 🔍 Symptom checker
- 👨‍⚕️ Browse and book certified pediatric doctors
- 📋 Manage appointments
- 💊 Order homeopathic medicines online
- 💬 File complaints and track resolution

### 👨‍⚕️ For Doctors
- 📝 Application & verification system
- 📊 Dashboard with patient appointments
- ✅ Accept/Reject/Complete appointment flow
- 👤 Profile management with photo
- 💬 Submit complaints

### 👑 For Admins
- 📋 Review doctor applications with document verification
- ✅ Approve/Reject doctors with auto-generated credentials
- 👨‍⚕️ Manage active doctors (suspend/delete)
- 💬 Handle user/doctor complaints
- 📊 System statistics

## 🛠️ Tech Stack

### Frontend
- **React 18** with React Router
- **Axios** for API calls
- **JWT** for authentication
- Custom glassmorphism design with animations

### Backend
- **Django 5.1+** with **Django REST Framework**
- **JWT Authentication** (Simple JWT)
- **SQLite** database
- **Pillow** for image handling

## 🚀 Getting Started

### Backend Setup

\`\`\`bash
cd backend
python -m venv venv
venv\\Scripts\\activate    # Windows
pip install -r requirements.txt
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
\`\`\`

### Frontend Setup

\`\`\`bash
npm install
npm start
\`\`\`
